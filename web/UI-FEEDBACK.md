# 加载反馈与主题滚动条

2026-10-08。加载提示延迟 100ms；请求超时策略保持原有设置，快速完成立即显示结果。

## 已实现

- 按钮即时按压反馈；登录、书源配置提交、刷新目录/章节等异步按钮 100ms 后显示转圈，保留按钮宽度和可访问名称。
- 网页启动层在 JS 尚未加载时也能显示延迟动画和“正在加载”。
- 搜索在首批结果前及流式搜索期间显示转圈和实际来源进度，保留停止、查看详情和入架；停止后清除动画并忽略晚到的结果。
- 目录只在当前点击的章节旁显示延迟动画；连续点选本地窗口内的章节仍由最后一次选择生效，较早请求不能清除新请求的提示。
- 书籍详情、书源配置、书架分页和书库加载接入局部反馈；复用原有全局消息，完成、失败、取消及离开页面会清除待显示的加载提示。
- 滚动条按浅色灰色、护眼棕色、深色浅灰色绘制；标准属性加 WebKit 回退，保留原先隐藏的滚动条，并尊重系统高对比与减少动画设置。

## 验证

相关 12 个测试文件共 127 项通过；TypeScript 检查及生产构建通过。新回归覆盖 100ms 边界、进度更新不重置计时、取消和卸载、忙碌按钮和目录连续点选。

`tools/ui-review/loading-feedback.mjs` 在生产构建上检查 Chromium、WebKit 的 390×844 手机与 1280×800 桌面布局：启动提示、首批结果前的动画、停止后的迟到响应、快速搜索不闪、按钮宽度、主题滚动条、减少动画、目录跳转及原有隐藏滚动条均通过。

```sh
npm run build
node tools/ui-review/loading-feedback.mjs
```

运行浏览器检查需要已安装 Playwright 的 Chromium 和 WebKit。测试使用本地模拟 API，不修改真实账号、书源或阅读记录。未验证 iPhone/Android 真机以及旧 WebView 的滚动条回退绘制；网页 HTML 尚未到达时应用无法显示启动提示。
