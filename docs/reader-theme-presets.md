# 阅读主题预设

阅读器的「外观 → 主题」统一选择整套主题。原有 21 套配色和 5 种纸色都保留，删除旧配色选择器、独立纸色和明暗控制。书架设置中的重复阅读配色入口同时移除。

- `shared/theme/theme.ts` 将原有颜色映射到完整的 V3 语义令牌，包括背景、正文、控制栏、弹窗、按钮和阅读频道颜色。自定义预设自带固定的浅色或深色模式；「跟随应用」「黑白灰」沿用应用模式。
- `AppSettings.readingTheme` 按设备保存阅读主题。应用级主题和明暗配置不受阅读选择或日夜快捷按钮影响。
- 旧的 `local-*` 纸色迁移为同名主题，其余纸色迁移为 `paper-*` 主题。已有新字段优先；没有独立纸色或新字段时，保留原作用域的阅读主题选择。
- 字号、亮度、行距、边距和日夜配色记忆保留；羊皮纸和牛皮纸纹理也保留。旧渲染器需要的 `--reader-*` 从同一组 V3 令牌生成。
- `paper` 在迁移后归一为 `theme`，避免退出主题后又恢复旧纸色；旧字段仅保留读取兼容。

验收：221 项主题、迁移、阅读行为和读数测试通过。`web/tools/ui-review/reader-unified-themes.mjs` 在 Chromium/WebKit、390/1280px 下逐项检查 112 次主题选择、正文与弹窗颜色、刷新持久化、日夜切换、原配置迁移和应用主题隔离。`reader-control-cycle.mjs` 的 8 组控制栏、读数定位及翻页锁定回归通过。

这次只整合阅读主题；iPhone 系统液态玻璃的真实设备表现仍需设备确认，浏览器模拟不等于系统合成层验证。
