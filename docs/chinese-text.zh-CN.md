# 正文繁简转换

全局提供「原文 / 简体 / 繁体」，默认原文。选择保存在当前设备，应用于所有书籍；不跟随账号同步到其他设备。

入口：

- 「书架设置 → 正文 → 繁简转换（全局）」。
- 阅读时「界面 → 正文 → 繁简转换（全局）」。

切换后立即重绘当前章节，保留章节与阅读进度；之后打开的书使用同一选项。支持网文章节、TXT、EPUB 和 RSS 等可重排正文。图片、扫描 PDF 和漫画画面不做文字识别。

原始书籍、章节缓存、链接与样式不会被覆盖。OpenCC 词库随前端打包，已缓存书籍离线时也能切换。书源原先已经简化的内容，不能由「原文」恢复成网站转换前的文字。

朗读使用当前显示的正文。切换文字时停止当前朗读，重新点击朗读后使用新的文字。复制选中文字使用显示文字；笔记、高亮与纠错保存原文锚点，支持转换后继续定位，包括 Unicode 兼容字归一化引起的长度变化。

启用简体或繁体时，书内搜索同时尝试输入词及其常用繁简写法，合并相同位置的结果；结果摘要使用当前文字选项。繁简转换属于词库转换，并不保证所有人名、古文或多义字都能符合作者用字。

验证：`npm test`、`npm run build`；浏览器检查 `node tools/ui-review/reader-chinese.mjs`，覆盖 Chromium / WebKit，390 / 1280 宽度，即时切换、页码保持、朗读、刷新恢复、跨书生效与两个设置入口。
